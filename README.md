# 🤖 Creatmenu Bot System

Multi-bot creator system for Telegram built with Python + Railway + GitHub.

---

## 🚀 Features

- ➕ Users can add their own bots
- 🗑 Delete bots
- 🤖 My Bots dashboard
- 📊 Admin statistics panel
- 📢 Broadcast system (all users + main bot)
- 📡 Force join channel system
- 🚫 Ban / Unban bots
- 🎥 TikTok / Instagram / Facebook downloader
- 🔐 Referral system (unlock extra bots)
- ⚙ Admin panel (keyboard buttons only)
